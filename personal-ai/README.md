# Personal AI prototype

A local-first Japanese personal AI research project. This export contains application source, tests, the project vision and roadmap, and native audio-analysis code. User recordings, transcripts, memory databases, credentials, runtime logs, and model weights are not included.

## Layout

- `personal_ai/`: application and processing modules
- `tests/`: automated tests
- `native/`: macOS audio-analysis helper
- `PROJECT_VISION.md`: long-term research direction
- `PROJECT_PLAN.md`: current development roadmap

The original development guide contains machine-specific operations and private runtime details, so it is not part of this public export. The source remains a prototype; review the roadmap before use.
