# 個人向けAI 開発計画

更新日: 2026-10-20。今回のユーザー指示を、今後の開発・再開・評価の基準とする。

## 短期ロードマップ（現在は変更可能）

変わらない北極星と設計原則は [PROJECT_VISION.md](PROJECT_VISION.md) を参照する。この計画の6層は技術状況と本人の優先度に応じて順序を更新する。

**現在の優先順位: 本人がすぐ使える暫定版を完成し、実際の利用評価へ進む。** Web/Ollama/録音ワーカーを稼働させたまま、録音一覧・日時・文字起こし検索・根拠表示・記憶/仮説の閲覧と本人による訂正・追加・ローカル会話・状態表示を統合し、操作試験後に配備する。現在実装中の画面・検索・状態情報をこの順で検証する。長時間試験、ASR品質の反復改善、自動開発は暫定版を妨げるため停止状態を保つ。録音取り込みサービスは継続する。

暫定版の次は、本人が使った結果と新しい情報をもとに、**全履歴を対象とした記憶統合**を進める。現在の統合器は最新24件を対象とする制限がある。ペア単位の出典・現行性を保ち、根拠の訂正・削除を局所反映し、同じ情報を何度も考察しない仕組みを作る。その後、イベントの理解、仮説の検証、応答品質の比較、経験に基づく人格適応、LoRA等の学習実験へ進む。SOAK24とASR_QUALITYは本人の明示的な再開まで停止する。

各短期リリースは北極星への研究過程の一部であり、6層の全完了や究極目標の達成とはしない。次に増えるユーザー能力、根拠、限界、次の研究課題を記録する。

## 最終目標

本人の日常を出来事として理解し、経験を蓄積・再構成し、人物関係、価値観、目標、感情についての不確実な手がかり、行動の変化を統合するパーソナルAIを目指す。新しい情報から自ら検証すべき問いを見つけ、仮説を支持・反証する根拠を比較し、理解を更新して会話に活用する。一貫した個性や好奇心を持ち、雑談・相談・共同の研究を自然に行い、対話と評価を通じて振る舞いを発展させる。

『転生したらスライムだった件』のラファエル先生のような知性は長期的な理想である。現時点で同等の理解や推論を実現したとは扱わない。難しい能力は研究課題と評価方法を残し、作りやすい基礎機能で目標を置き換えない。

録音の文字起こし、検索、ローカルチャット、固定の人格設定、定期ジョブ、24時間稼働は基盤である。これらが動いてもプロジェクト全体を完成にしない。上位層は、記憶・考察・適応が回答や訂正への追随を実際に改善した証拠を必要とする。

## 状態の読み方

- **実装済み**: 明記した範囲の機能とテストがある。実録音での精度、長期的な理解、上位層の完成を意味しない。
- **開発中**: 部分実装または検証中。合格していない評価を併記する。
- **未着手**: 実行可能な実装がない。依存条件と次の作業は `TASKS.md` に記す。
- **研究段階**: 方法と評価を選定する段階。効果や実現可能性は未確認。

実行状態の正本は `.development/state.sqlite3`。この文書の能力状態と、個別タスクの `COMPLETED` は範囲が異なる。たとえば環境音を推測として保存するタスクが完了しても、生活状況を正しく理解できたことにはならない。

## 第2層: 経験の理解

| 状態 | 現在あるもの・残るもの | 根拠・評価 |
|---|---|---|
| 実装済み | RMS/ピーク音量、無音区間、文字起こし由来の代理話速 | `audio_features.py`。これは音響的観測で、感情の確定ではない |
| 開発中 | 匿名話者分離、発言との時刻照合、重複発話 | `diarization.py`、`speaker_alignment.py`。合成2話者の実行確認済み。実録音の分離精度・長時間性能は未評価 |
| 未着手 | 本人の声の明示的登録、未知話者の保留、同意に基づく第三者の登録 | `VOICE_ID`。匿名ラベルを人物IDとして使わない |
| 開発中 | 環境音の時刻付き推測ラベル | `environment_sound.py`。ローカル推論は実行済み。ラベルの実録音精度と生活状況への統合は未了 |
| 開発中 | 明示的な好み・価値観・予定の候補抽出 | `memory_candidates.py` は3種類の定型表現を扱う。一般的な出来事理解や人物帰属は未実装 |
| 開発中 | 発言・話者・音響観測・環境音を統合した出来事、人物、状況の表現 | `EXPERIENCE_INTEGRATION` に根拠ID・時刻付きの統合タイムラインとWeb画面を実装。観測とモデル推測を分離。出来事の意味や人物・状況の推論は未実装 |
| 研究段階 | 声の抑揚、笑い・ため息、会話の雰囲気、感情の可能性 | emotion2vec+等は比較対象。日本語・日常録音の妥当性と棄却条件を評価し、診断や心理の断定に使わない |

出来事は「何が、いつ、誰に関して起きた可能性があるか」と根拠音声区間を保持する。人物や場所の不明を許容し、同じ声らしさや環境音から身元・学校等を決めつけない。

検索は過去の情報を取り出す手段として拡張する。長期記憶の到達基準は、同じ内容の整理、例外の保持、新旧の文脈と訂正の追随、根拠を保った応答改善である。

| 状態 | 現在あるもの・残るもの | 根拠・評価 |
|---|---|---|
| 実装済み | 確認済み記憶にリンクする日次・週次ログ、新情報なしの停止 | `reflection.py` の既存機能は根拠一覧と定型の結論。深い振り返りの実現とは扱わない |
| 開発中 | 検証すべき問い、仮説、支持・反証、改訂、次の検証事項を保存するループ | 今回の `HYPOTHESIS_LOOP`。まず合成経験による仕組みの検証を行う。実際の理解・応答品質の改善は別途評価 |
| 未着手 | 新しい出来事から矛盾・不足情報を発見し、目的と予算を持つ検証課題を選ぶ | 根拠追加・訂正を契機に再評価し、同じ材料で無限に考察しない |
| 未着手 | 長期間の情報を使う再解釈、仮説の比較、継続的研究 | 結論の確信度だけでなく反証と代替説明を保存し、本人への確認候補を作る |

ループは「新規情報または根拠の訂正 → 問い → 根拠選択 → 支持・反証・不明の判定 → 仮説改訂 → 次に確かめること」の形にする。記録するのは目的、根拠への参照、判断結果、限界、次の作業である。考察自身を独立した事実として再利用して確信を水増ししない。

| 状態 | 現在あるもの・残るもの | 根拠・評価 |
|---|---|---|

| 研究段階 | 軽量/高性能ローカルモデル、別計算機、許可された外部モデルへの委任 | `MODEL_ROUTING`。ローカルから始め、外部委任は対象・目的・料金の許可を明示し、既定無効を維持 |
| 開発中 | 記憶・考察・適応による長期の会話品質改善の実証 | `QUALITY_EVAL` に合成6ケース×3条件の予備比較器を実装。実ローカル回答18件を生成したが、意味の正しさ・有用性は未採点で、改善を実証したとは扱わない |

高性能モデルへの変更だけを理解の改善とみなさず、同じ評価課題・同じモデル条件で記憶や考察の寄与を測る。モデル委任を実装しても個人録音・記憶の送信許可にはならない。

## 将来構想: 仮想的な人生・社会・経験

**研究段階**。仮想の学校生活、友人関係、成功・失敗、時間による価値観の変化、物理的環境、複数エージェントの社会、研究・創作を経験する構想を維持する。現在の実装範囲には仮想世界の構築を含めない。

`VIRTUAL_EXPERIENCE` では、現実の録音・対話、架空設定、シミュレーション内の出来事を異なる出自として扱う設計から始める。仮想の経験を本人の現実の出来事に混ぜず、人格に与えた変更も遡れるようにする。小さな再現可能な環境で、経験による変化と単なるランダムな変動を比較する。

## 共通の評価と進め方

1. **品質を支える入力**: 反復誤認識を含むASRを改善し、聞き取り不能・話者不明を保った出来事の構造へ進む。
2. **今回進める縦の経路**: 合成の確認済み経験で、仮説の支持・反証・訂正・再評価・停止を実装する。実録音が未評価でもこの仕組みを独立して検証できる。
3. **比較評価**: 記憶なし、検索のみ、検索＋考察を同じ質問・モデル・設定で比較する。課題達成、誤断定、根拠の正しさ、訂正追随、応答時間・メモリ・費用を記録する。人格・会話の自然さは本人による評価も必要。
4. **統合と適応**: 出来事統合、人物関係、意味記憶、経験による方針改訂へ進み、追加学習の小規模試験を行う。
5. **運用と長期実証**: 24時間試験に加え、複数日・週の経験と訂正で理解が更新されることを評価する。

機構テストの成功、合成音声の成功、モデルが返した結論だけでは、実生活を正しく理解した証明にならない。評価データ、実行条件、結果、未評価部分を残す。研究実験が不成功でも目的を削除せず、原因、代替案、再試行条件を保存する。

MacBook M5・24GBを中心に、モデル交換と別計算環境への移行を可能にする。重い処理の同時実行を抑え、イベント駆動と予算付きジョブを用いる。開発自動化は1回1タスク・30分以内、最大3回の失敗でBLOCKEDとし、独立タスクを進める。録音原本は変更せず、個人録音・記憶・秘密を開発用外部AIへ渡さない。クラウド利用と追加課金は明示的許可がある場合のみ。Gitチェックポイントはテスト成功後だけ残す。

## 2026-10-20の優先順位変更

本人指示でASR品質改善の開発・関連精度評価を一時停止し、録音整理・根拠付き出来事抽出・長期記憶の整理・自律考察を最優先にする。取り込み・Web・稼働監視は継続。RECORDING_KNOWLEDGEに抽出、関連候補、訂正伝播、UI、周期処理をまとめ、実録音の意味精度と有用性は別途検証する。OpenClawは管理層の比較候補として扱い、隔離試験を行うまで個人データや広範囲シェル権限を渡さない。長期目標と追加学習の研究計画は維持する。
